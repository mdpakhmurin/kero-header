Исключить фотографию?

Фотография больше не будет участвовать в генерации. Её можно вернуть во вкладке «Исключённые».

Подключение VK

Фотографии загружаются через API VK. Нужен токен, которому доступны выбранные методы чтения фото и стены.

Токен хранится только в памяти сервера до его перезапуска. Для постоянного подключения можно задать VK_TOKEN в локальном файле .env.
