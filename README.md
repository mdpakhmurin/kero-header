# Kero Header Studio

Локальный веб-сервис для создания обложки `vk.ru/kero_comics` из случайно наложенных фотографий. Node.js 22 или новее, современный браузер. Внешних npm-зависимостей нет.

## Запуск

В Windows дважды щёлкните **`start.cmd`** в папке проекта. Сервер запустится, а редактор автоматически откроется в браузере. Окно запуска оставьте открытым; для остановки закройте его или нажмите `Ctrl+C`. Повторный запуск откроет страницу уже работающей программы. Требуется установленный Node.js 22 или новее.

Запуск через терминал:

```powershell
cd C:\Projejcts\kero-header
npm start
```

Откройте http://localhost:3210. Остановка — `Ctrl+C` в терминале. Для разработки с перезапуском сервера: `npm run dev`. Сервер слушает только `127.0.0.1`.

## Фотографии из VK

1. Нажмите **Синхронизировать VK**: без токена откроются настройки. Шестерёнка рядом всегда открывает настройки, даже если токен уже задан. Ссылка `https://vk.ru/kero_comics` уже указана.
2. Укажите токен, которому разрешены нужные методы VK API. Для полного сбора нужен пользовательский токен: `photos.getAll` в официальной схеме поддерживает тип `user`; доступ к стене также зависит от прав и ограничений VK. Токен сообщества не является универсальной заменой.
3. Выберите «Альбомы и фотографии из постов» и нажмите **Синхронизировать VK**.
4. При отсутствии доступа к одному из источников приложение сохранит доступные фото из другого и покажет предупреждение. Можно выбрать только альбомы или только стену.

Токен из интерфейса хранится только в памяти сервера. Он не возвращается клиенту и не записывается в настройки. Для сохранения между запусками скопируйте `.env.example` в `.env` и задайте `VK_TOKEN`. `.env` исключён из Git. Не вставляйте токен в URL или в коммит.

Официальные источники: [токены VK](https://dev.vk.com/ru/api/access-token/getting-started), [схема методов photos](https://github.com/VKCOM/vk-api-schema/blob/master/photos/methods.json), [схема методов wall](https://github.com/VKCOM/vk-api-schema/blob/master/wall/methods.json). Используется API 5.199 по адресу `https://api.vk.ru/method/`. Получение токена и доступность методов зависят от приложения VK и аккаунта; встроенной авторизации OAuth здесь нет.

Сбор проходит все страницы альбомов и стены, включая фотографии во вложенных репостах. Одинаковые фото объединяются по `owner_id` и `photo_id`, берётся максимальный доступный размер. «Все фото» означает доступные токену фотографии из выбранных источников; комментарии, видео, документы и закрытые материалы не обходятся.

Можно работать без VK: **Добавить файлы** импортирует JPEG, PNG и WebP до 30 МБ каждый. Повторный импорт одинакового файла не создаёт копию.

## Редактор

- Настройте размеры холста, размер фотографий и случайное отклонение размера, угол вращения, случайность позиций, рамку, тень и фон. Размер задаёт базовую ширину в пикселях, отклонение — случайный разброс ± в пикселях. Например, 300 px и ±50 px дают ширину от 250 до 350 px; нулевое отклонение делает ширину одинаковой. Рамка и тень также регулируются ползунками. Генерация использует все доступные неизъятые фото.
- **Перемешать кадры** каждый раз создаёт новое случайное зерно и новую композицию. Зерно сохраняется в файле настроек автоматически.
- Перетащите фото мышью. Колесо меняет размер выбранного кадра, `Shift + колесо` — угол. Панель под холстом позволяет задать точные значения и порядок слоёв.
- **Убрать с холста** / `Delete` удаляет фото только из текущей композиции. При следующей генерации оно может вернуться.
- **Исключить навсегда** или `×` в библиотеке записывает ID в список исключений. Фото больше не участвует в генерации и не скачивается при синхронизации. Вернуть его можно во вкладке «Исключённые»; после восстановления отсутствующего файла запустите синхронизацию.
- `Ctrl+Z` отменяет последние изменения композиции (до 50 шагов в текущей вкладке). Исключения восстанавливаются отдельно через библиотеку.
- Параметры и исключения сохраняются автоматически. Раскладка существует только в памяти открытой вкладки: координаты и порядок слоёв не отправляются на сервер и не записываются на диск. После обновления страницы холст пустой. Параметры размера фото, вращения и случайности применяются при следующей генерации; фон, рамка, тень и размеры холста — сразу. Изменение размера холста не масштабирует ручные координаты.
- **Скачать PNG** экспортирует в указанных размерах из оригинальных изображений, без рамки выделения. Экспорт не публикует обложку в VK.

## Хранение и Git

Кнопка **Очистить кеш** удаляет локальные изображения после подтверждения и очищает текущий холст. Индекс фотографий, настройки и исключения сохраняются. Фотографии VK можно скачать снова синхронизацией, а добавленные с компьютера файлы — импортировать повторно. Во время синхронизации очистка недоступна.

| Путь | Содержимое | Коммитить |
| --- | --- | --- |
| `config/settings.json` | Сообщество, источник, параметры генерации, зерно | Да |
| `config/exclusions.json` | Стабильные ID исключённых фото | Да |
| `cache/library.json` | Индекс фото, ссылки VK, контрольные суммы | Нет |
| `cache/images/` | Скачанные и импортированные оригиналы | Нет |
| `.env` | Локальный токен и необязательный `PORT` | Нет |

Файлы JSON можно редактировать вручную при остановленном сервере. Сохранение выполняется через временный файл и переименование. При копировании проекта на другой компьютер синхронизируйте VK, чтобы заново наполнить кеш. Локальные фотографии импортируйте повторно: их ID рассчитывается по содержимому, поэтому исключения сохранятся для идентичных файлов. Раскладка не сохраняется и не переносится через Git.

Каждая синхронизация получает свежие ссылки VK и проверяет SHA-256 файлов. Исправные изображения не загружаются повторно; отсутствующие и повреждённые восстанавливаются. Случайно удалённый локально импортированный файл нужно импортировать снова. Фото, удалённые **в самом VK**, автоматически из кеша не удаляются: локальный архив сохраняется. Если такой файл потерян и его старый адрес больше не работает, восстановить его из VK невозможно — приложение сообщает об этом. Проверка состояния при открытии страницы обнаруживает отсутствующие файлы; проверка контрольных сумм выполняется при синхронизации.

Предпросмотр уменьшает изображения до 1200 px по длинной стороне, но большое число изображений всё равно требует памяти браузера. PNG экспортируется последовательно из оригиналов. У каждой вкладки своя временная раскладка; настройки и исключения общие.

## Проверки

```powershell
npm test
```

Тестируются воспроизводимость генерации, геометрия выбора, валидация, пагинация VK, репосты, дедупликация, пропуск кеша, восстановление удалённых и повреждённых файлов, исключения, частичный доступ VK, передача токена и HTTP-сохранение настроек после перезапуска, отсутствие сохранения раскладки и очистка кеша. VK в тестах подменяется: реальная загрузка требует вашего токена и сетевого доступа.

Для отдельной визуальной проверки с синтетическими изображениями: `node scripts/preview-demo.mjs`, затем http://localhost:3211. Демонстрация использует новую папку во временном каталоге системы и не меняет рабочие настройки/архив. Остановка — `Ctrl+C`.
