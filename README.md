# Редактор обложек Ке’Ро

Собирайте обложки из своих фотографий или изображений из сообщества VK. Готовую работу можно скачать в PNG или установить в VK.

## Как пользоваться

1. Откройте библиотеку кнопкой с папкой. Загрузите фотографии или подключите VK, выберите кадры и нажмите **Добавить**.
2. Выберите размер холста, настройте фотографии и нажмите **Перемешать кадры**. На пустом холсте используются все доступные фото, на заполненном — только уже добавленные.
3. Доработайте композицию вручную и скачайте результат через **Экспорт PNG**.

- Нажатие на фото в библиотеке выделяет его. Лупа открывает просмотр, меню действий позволяет переименовать, отметить избранным, исключить или удалить фотографию.
- На компьютере перетаскивайте кадры мышью: колесо поворачивает, Shift + колесо меняет размер. На телефоне перемещайте одним пальцем, меняйте размер и поворот двумя.
- В просмотрщике на телефоне листайте свайпом и увеличивайте фото двумя пальцами.
- **Исключить** оставляет фото в библиотеке, но убирает из генерации. **Удалить** убирает его из вашей библиотеки. Исходный файл на компьютере не меняется.
- **Сохранить настройки** сохраняет параметры редактора. Отмена и повтор: Ctrl+Z и Ctrl+Shift+Z / Ctrl+Y.

В аккаунте доступны личная библиотека и подключение VK. В деморежиме фотографии остаются только в этом браузере; синхронизации VK нет. Очистка данных сайта удалит фотографии демо.

## Как запустить

**Обычный запуск** — нужен Node.js 22.13 или новее:

| Система | Запуск | Остановка |
| --- | --- | --- |
| Windows | Двойной клик `launch/local/windows/start.cmd` | `launch/local/windows/stop.cmd` |
| Linux | `sh launch/local/linux/start.sh` | `sh launch/local/linux/stop.sh` |

**Через Docker** — нужен запущенный Docker с Compose (в Windows — Docker Desktop):

| Система | Запуск | Остановка |
| --- | --- | --- |
| Windows | Двойной клик `launch/docker/windows/start.cmd` | `launch/docker/windows/stop.cmd` |
| Linux | `sh launch/docker/linux/start.sh` | `sh launch/docker/linux/stop.sh` |

Откройте **http://localhost:3210**. Остановка сохраняет фотографии и настройки. Перед запуском другим способом остановите уже работающий редактор.

**Демо для GitHub Pages:** выполните `npm run build:demo` и опубликуйте папку `dist/demo/`. Для автоматической публикации из `main` выберите в настройках репозитория **Pages → Source → GitHub Actions**. Локальный просмотр демо: `npm run preview:demo`, адрес **http://localhost:3212**.
