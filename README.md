# Kero Header Studio

Локальный редактор обложек `vk.ru/kero_comics` с фотобиблиотекой и просмотрщиком изображений. Node.js 22 или новее, современный браузер. Внешних npm-зависимостей нет.

## Запуск

В Windows дважды щёлкните **`start.cmd`** в папке проекта. Сервер запустится, а редактор автоматически откроется в браузере. Окно запуска оставьте открытым; для остановки закройте его или нажмите `Ctrl+C`. Повторный запуск откроет страницу уже работающей программы. Требуется установленный Node.js 22 или новее.

Запуск через терминал:

```powershell
cd C:\Projejcts\kero-header
npm start
```

Откройте http://localhost:3210. Остановка — `Ctrl+C` в терминале. Для разработки с перезапуском сервера: `npm run dev`. Сервер слушает только `127.0.0.1`.

## Демо-режим

Переключатель **Основной / Демо** находится справа в шапке. В демо там же появляется отметка **Демо-режим**. Для прямого открытия демо используйте `http://localhost:3210/?mode=demo`; основной режим — `?mode=local`. Выбор запоминается в браузере, явный параметр ссылки имеет приоритет.

После первоначальной загрузки HTML, стилей и модулей демо не обращается к серверному API и не читает изображения с сервера. Сетевые соединения дополнительно запрещены политикой страницы. Доступны только загруженные пользователем фотографии; раздел VK, синхронизация и установка обложки в VK скрыты. Просмотрщик, холст, перетасовка, история и экспорт PNG работают в браузере, в том числе после отключения сервера у уже открытой страницы.

Настройки, названия размеров и исключения сохраняются в IndexedDB `kero-demo-v1`. Оригиналы загруженных файлов хранятся там же как Blob и показываются через локальные `blob:`-адреса. Файлы не отправляются на сервер, не записываются в папку проекта и остаются доступными после обновления страницы. Настройки записываются общей кнопкой **Сохранить настройки**; фотографии и исключения — сразу после соответствующего действия. Кнопка **Очистить файлы** в демо очищает только фотографии этого браузерного хранилища. Данные привязаны к браузеру и адресу сайта; очистка данных сайта удаляет их.

Режимы используют разные настройки, библиотеки и кеши предпросмотра. Переключение перезагружает редактор и очищает текущий холст; при несохранённых настройках или заполненном холсте появляется предупреждение. Переключение само по себе не переносит файлы между режимами. Для публикации демо достаточно раздать содержимое `public/` статическим хостингом по HTTPS и открыть страницу с `?mode=demo`; серверная часть Node.js ему не нужна.

## Фотографии из VK

Кнопка **Установить обложку** над холстом открывает предпросмотр и подтверждение замены обложки VK. Ссылка на паблик подставляется из настроек синхронизации, но её можно изменить для одной установки. Используется PNG с оригиналами фотографий и сглаживанием, как при экспорте; рамка интерфейса в него не попадает. Требуется токен с доступом к изменению обложки выбранного сообщества. Он берётся из подключения VK; изменить его можно прямо из модалки. Установка использует официальные методы [photos.getOwnerCoverPhotoUploadServer и photos.saveOwnerCoverPhoto](https://github.com/VKCOM/vk-api-schema/blob/master/photos/methods.json).

1. Нажмите **Синхронизировать VK**: без токена откроются настройки. Шестерёнка рядом всегда открывает настройки, даже если токен уже задан. Ссылка `https://vk.ru/kero_comics` уже указана.
2. Укажите токен, которому разрешены нужные методы VK API. Для полного сбора нужен пользовательский токен: `photos.getAll` в официальной схеме поддерживает тип `user`; доступ к стене также зависит от прав и ограничений VK. Токен сообщества не является универсальной заменой.
3. Выберите «Альбомы и фотографии из постов» и нажмите **Синхронизировать VK**.
4. При отсутствии доступа к одному из источников приложение сохранит доступные фото из другого и покажет предупреждение. Можно выбрать только альбомы или только стену.

Токен из интерфейса хранится только в памяти сервера. Он не возвращается клиенту и не записывается в настройки. Для сохранения между запусками скопируйте `.env.example` в `.env` и задайте `VK_TOKEN`. `.env` исключён из Git. Не вставляйте токен в URL или в коммит.

Официальные источники: [токены VK](https://dev.vk.com/ru/api/access-token/getting-started), [схема методов photos](https://github.com/VKCOM/vk-api-schema/blob/master/photos/methods.json), [схема методов wall](https://github.com/VKCOM/vk-api-schema/blob/master/wall/methods.json). Используется API 5.199 по адресу `https://api.vk.ru/method/`. Получение токена и доступность методов зависят от приложения VK и аккаунта; встроенной авторизации OAuth здесь нет.

Сбор проходит все страницы альбомов и стены, включая фотографии во вложенных репостах. Одинаковые фото объединяются по `owner_id` и `photo_id`, берётся максимальный доступный размер. «Все фото» означает доступные токену фотографии из выбранных источников; комментарии, видео, документы и закрытые материалы не обходятся.

Можно работать без VK: **Добавить файлы** импортирует JPEG, PNG и WebP до 30 МБ каждый. Повторный импорт одинакового файла не создаёт копию.

Кнопка с иконкой папки **Библиотека** над холстом открывает модальное окно. Клик по фотографии выбирает её; можно отметить несколько фото в разных вкладках и фильтрах, затем нажать **Добавить**. Группа добавляется одним действием истории, повторный выбор тех же фото создаёт независимые копии. **Отмена** или `Esc` закрывают библиотеку без добавления. **Исключить** применяет исключение ко всей выбранной группе после подтверждения; для выбранных исключённых фото эта кнопка восстанавливает участие в генерации. Импорт и синхронизация обновляют библиотеку, а добавление на холст происходит только по кнопке **Добавить**.

Лупа на карточке открывает просмотрщик: крупное изображение, стрелки влево/вправо и ряд миниатюр снизу. Просмотрщик использует текущий фильтр и порядок сортировки всей библиотеки, включая ещё не загруженные в сетку фото. Можно листать клавишами `←` / `→`, переходить к первому и последнему кадру через `Home` / `End`, закрывать окно через `Esc`. Кнопка источника на карточке или в просмотрщике открывает пост VK, страницу фотографии VK или локальный оригинал. При прокрутке библиотеки карточки добавляются автоматически порциями, изображения загружаются лениво. Для ссылок на посты у ранее загруженных фото повторите синхронизацию VK.

В тёмном просмотрщике колесо мыши и кнопки `−` / `+` меняют масштаб; увеличенное фото можно перетаскивать. Число процентов показывает реальный масштаб относительно оригинала: нажмите его для 100%. Кнопка вписывания и клавиша `0` возвращают фото целиком в окно. Панель параметров редактора закреплена слева, действия над выбранным кадром появляются рядом с ним.

## Редактор

Кнопка в шапке параметров плавно сворачивает панель; для возврата кнопка появляется в шапке холста. Редактор расширяется на освободившееся место; состояние панели запоминается в браузере. Предпросмотр целиком вписывается в доступную ширину и высоту окна, в том числе для квадратных и вертикальных холстов. Размер PNG при экспорте остаётся выбранным в параметрах. «Порядок кадров» сохраняется общей кнопкой **Сохранить настройки** вместе с остальными параметрами.

- Размер холста выбирается из списка слева. Пункт **＋ Добавить размер…** открывает окно с названием, шириной и высотой; **Добавить и выбрать** сразу применяет новый размер. В строках выпадающего списка карандаш переименовывает размер, а корзина удаляет его после подтверждения. Переименование другого варианта не меняет выбранный размер; при удалении текущего холст переключается на соседний вариант. Последний размер удалить нельзя. Название необязательно, его можно очистить. Чтобы записать изменения в `config/settings.json`, нажмите **Сохранить настройки** в панели слева. Названия хранятся в поле `name` элементов `coverSizes` вместе с `width` и `height`.
- Настройте размеры холста, базовый размер фотографий (20–800 px), отклонение размера (0–300%), угол вращения, рамку, тень и фон. Для каждого ползунка есть синхронизированное поле ввода числа. Отклонение задаёт случайный разброс ± в процентах от базовой ширины: 300 px и 50% дают 150–450 px. При 0% ширина одинакова. При больших процентах нижняя граница ограничивается 20 px; например, 300 px и 300% дают 20–1200 px. Старые настройки в пикселях преобразуются при загрузке, а новая форма записывается кнопкой сохранения. Генерация использует все доступные неизъятые фото и подбирает позиции по свободным участкам холста с учётом реальных пропорций, поворота и рамки. Крупные кадры размещаются первыми, следующие закрывают оставшиеся просветы, включая края и углы. При недостаточной суммарной площади фото полное покрытие невозможно.
- Под холстом отображается примерный процент пустого пространства. Он обновляется после генерации, перемещения, поворота, изменения размера, удаления и восстановления кадров. Фото и рамки считаются заполнением; тени и рамка выделения — нет.
- **Перемешать кадры** каждый раз создаёт новую случайную композицию. Случайное зерно используется только при генерации и не сохраняется в настройках.
- Перетащите фото мышью. Колесо вращает выбранный кадр, `Shift + колесо` меняет его размер. При выборе кадра рядом появляется панель с кнопками порядка слоёв и удаления: на один слой вперёд/назад или сразу на передний/задний план. Потяните за угол рамки, чтобы пропорционально изменить размер; круглый маркер над кадром вращает его (`Shift` — шаг 15°). Все ручные изменения поддерживают отмену и повтор. Панель и маркеры не попадают в PNG.
- **Убрать с холста** / `Delete` удаляет фото только из текущей композиции. При следующей генерации оно может вернуться.
- **Исключить** в библиотеке или кнопка исключения на панели выбранного кадра записывает ID в список исключений. Фото не участвует в генерации, но скачивается и восстанавливается при синхронизации наравне с остальными. Вернуть его в генерацию можно во вкладке «Исключённые».
- Кнопки **↶** и **↷** отменяют и повторяют изменения композиции (до 50 шагов в текущей вкладке). Горячие клавиши: `Ctrl+Z` — отмена, `Ctrl+Shift+Z` или `Ctrl+Y` — повтор. Новое изменение после отмены очищает ветку повтора. Исключения восстанавливаются отдельно через библиотеку.
- Параметры редактора записываются в файл только кнопкой **Сохранить настройки**. Перемешивание и экспорт используют текущие параметры без сохранения; импорт и синхронизация не сбрасывают несохранённые параметры. После обновления страницы возвращаются последние сохранённые настройки. Подключение VK сохраняется отдельной кнопкой **Сохранить подключение**, исключения сохраняются сразу. Раскладка существует только в памяти открытой вкладки: координаты и порядок слоёв не отправляются на сервер и не записываются на диск. После обновления страницы холст пустой. Параметры размера фото и вращения применяются при следующей генерации; фон, рамка, тень и размеры холста — сразу. Изменение размера холста не масштабирует ручные координаты.
- Предпросмотр учитывает плотность пикселей экрана. Фото уменьшаются поэтапно с качественной фильтрацией, а композиция рисуется с запасом разрешения и затем уменьшается для сглаживания повёрнутых краёв и мелких деталей.
- **Экспорт PNG** экспортирует в указанных размерах из оригинальных изображений, без рамки выделения, с тем же сглаживанием. Для обычных обложек используется двукратное разрешение промежуточного холста; на больших размерах оно ограничивается для экономии памяти. Экспорт не публикует обложку в VK.

## Хранение и Git

Кнопка **Удалить файлы** вверху библиотеки удаляет файлы только выбранного источника после подтверждения. Кадры другого источника остаются на холсте. Для VK сохраняются записи и исключения, чтобы скачать фото повторной синхронизацией. Для компьютера удаляются копии и записи из проекта, включая исключённые; исходные файлы пользователя остаются. Во время синхронизации удаление недоступно.

Оригиналы хранятся в `cache/images` внутри папки проекта с расширениями `.jpg`, `.png` и `.webp`; весь `cache/` исключён из Git через `.gitignore`. Старые файлы `.img` автоматически переименовываются при запуске, содержимое не меняется. Иконка вкладки использует голубя из исходной иллюстрации.

| Путь | Содержимое | Коммитить |
| --- | --- | --- |
| `config/settings.json` | Сообщество, источник, параметры генерации | Да |
| `config/exclusions.json` | Стабильные ID исключённых фото | Да |
| `cache/library.json` | Индекс фото, ссылки VK, контрольные суммы | Нет |
| `cache/images/` | Скачанные и импортированные оригиналы | Нет |
| `.env` | Локальный токен и необязательный `PORT` | Нет |

Файлы JSON можно редактировать вручную при остановленном сервере. Сохранение выполняется через временный файл и переименование. При копировании проекта на другой компьютер синхронизируйте VK, чтобы заново наполнить кеш. Локальные фотографии импортируйте повторно: их ID рассчитывается по содержимому, поэтому исключения сохранятся для идентичных файлов. Раскладка не сохраняется и не переносится через Git.

Каждая синхронизация получает свежие ссылки VK и проверяет SHA-256 файлов. Исправные изображения не загружаются повторно; отсутствующие и повреждённые восстанавливаются. Случайно удалённый локально импортированный файл нужно импортировать снова. Фото, удалённые **в самом VK**, автоматически из кеша не удаляются: локальный архив сохраняется. Если такой файл потерян и его старый адрес больше не работает, восстановить его из VK невозможно — приложение сообщает об этом. Проверка состояния при открытии страницы обнаруживает отсутствующие файлы; проверка контрольных сумм выполняется при синхронизации.

Предпросмотр уменьшает изображения до 1200 px по длинной стороне, но большое число изображений всё равно требует памяти браузера. PNG экспортируется последовательно из оригиналов. У каждой вкладки своя временная раскладка; настройки и исключения общие.

События перемещения, поворота и изменения размера объединяются в кадры браузера. Во время редактирования одного фото остальные слои и их тени берутся из временных буферов; после завершения действия буферы освобождаются. Расчёт пустой площади выполняется после короткой паузы. Размеры предпросмотра пересчитываются при изменении окна или холста. Качество сглаживания и экспорт из оригиналов сохраняются.

При открытии редактора пустой холст не загружает всю библиотеку. Миниатюры загружаются при открытии и прокрутке библиотеки, а недостающие размеры оригиналов определяются только для сортировки «Пропорции». Загрузка фотографий на холст выполняется очередью, чтобы параллельные действия не освобождали используемые изображения.

После первой подготовки уменьшенные изображения сохраняются в браузере в фоне. При следующем открытии редактора первая перетасовка использует эти предпросмотры вместо повторного чтения оригиналов. Кеш ограничен 128 МБ; устаревшие и удалённые из проекта фото из него убираются. Первичная подготовка новой фотографии по-прежнему требует оригинал. Предпросмотры сохраняются без потери качества в PNG, а экспорт всегда использует оригиналы из проекта. Если браузер запрещает кеширование, редактор работает без него.

## Проверки

```powershell
npm test
```

Тестируются воспроизводимость генерации, геометрия выбора, валидация, пагинация VK, репосты, дедупликация, пропуск кеша, восстановление удалённых и повреждённых файлов, исключения, частичный доступ VK, передача токена и HTTP-сохранение настроек после перезапуска, отсутствие сохранения раскладки и очистка кеша. VK в тестах подменяется: реальная загрузка требует вашего токена и сетевого доступа.

Для отдельной визуальной проверки с синтетическими изображениями: `node scripts/preview-demo.mjs`, затем http://localhost:3211. Демонстрация использует новую папку во временном каталоге системы и не меняет рабочие настройки/архив. Остановка — `Ctrl+C`.

При исключении фотографии появляется подтверждение. Во время перемешивания кнопка блокируется, а ход генерации отображается под холстом, над нижней информационной строкой: этап, процент и тонкая полоса прогресса.

Кнопки действий находятся поверх фотографий. Исключение и удаление файлов подтверждаются в модальном окне редактора. В модальной библиотеке прокручивается сетка фотографий, нижняя панель действий всегда видна; смена вкладки сохраняет выбранные фотографии. Отмена и повтор (`Ctrl+Z`, `Ctrl+Shift+Z`, `Ctrl+Y`) работают и с русской раскладкой.

Размер холста выбирается в собственном выпадающем списке редактора; стрелки, Enter и Escape доступны с клавиатуры. Кнопки на фотографиях появляются при наведении или фокусе, на сенсорном экране видны постоянно.

Компактная кнопка «Очистить холст» рядом с перемешиванием в шапке холста убирает все кадры с холста; очистка поддерживает отмену и повтор. Кнопкой добавления на фото можно создать несколько независимых копий: размер, угол и слой каждой копии редактируются отдельно. Исключение фотографии действует на все её копии.

Библиотека разделена на вкладки «Из VK» и «С компьютера». Для VK доступны фильтры «Доступные», «Исключённые» и «Нет в кеше», для компьютера — «Добавленные» и «Исключённые». Сортировка по соотношению сторон использует исходные ширину / высоту; в VK также доступна сортировка по дате фотографии. Повторный клик по активной сортировке меняет направление: широкие/узкие или новые/старые. Фотографии без даты или размеров идут в конце списка. Кнопка сохранения настроек расположена первой над разделительной линией.

Кнопка «Очистить файлы» вверху библиотеки действует на выбранный источник. Во вкладке VK удаляются скачанные файлы текущего сообщества, записи и исключения сохраняются для повторной синхронизации. Во вкладке компьютера удаляются копии файлов, записи и их исключения из проекта; исходные файлы пользователя остаются. Фотографии другого источника и его кадры на холсте сохраняются. Во вкладке компьютера доступны только «Добавленные» и «Исключённые».

Во вкладке «С компьютера» доступна сортировка «По дате» в обоих направлениях. Новые импорты получают постоянную дату добавления в индекс библиотеки. Для старых импортов дата однократно определяется по дате создания копии файла в проекте (при отсутствии — по дате изменения). Повторный импорт того же файла сохраняет первоначальную дату. Если старый файл отсутствует, неизвестная дата остаётся в конце списка.

«Перемешать кадры» на пустом холсте использует всю доступную библиотеку. Если холст заполнен, перемешиваются только размещённые кадры; количество копий одного фото и их независимые идентификаторы сохраняются.

Кнопки загрузки и синхронизации находятся перед удалением файлов в своих вкладках «Загруженное» и «Vk». В просмотрщике кнопка с плюсом закрывает просмотр и библиотеку, затем добавляет копию текущей фотографии на холст. Клик по фону за модальным окном закрывает его. Параметр «Порядок кадров» сохраняется кнопкой настроек: случайно, сначала новые или сначала старые. Для Vk используется дата фотографии, для загруженных — дата добавления. Приоритетные кадры размещаются первыми и рисуются поверх остальных; неизвестные даты не получают приоритета.

Размер **1400 × 280 (Пикабу)** доступен в списке холста. Строка прогресса занимает постоянное место над нижней информационной строкой, поэтому перемешивание не меняет масштаб предпросмотра. Декодированные изображения для ближайших отмены и повтора сохраняются в памяти: возврат заполненного холста после отмены не загружает те же фотографии заново.
